# شبیه‌سازی معاملات اهرمی (فقط آموزشی)

این قابلیت فقط شبیه‌سازی است و هیچ اتصال یا توانایی ثبت سفارش در نوبیتکس یا بروکر دیگری ندارد.

## محافظ‌ها
- سقف فعلی اهرم در شبیه‌ساز: ۳ برابر.
- پیش از ساخت موقعیت فرضی، دروازهٔ ریسک مستقل بررسی می‌شود.
- سقف سفارش و موقعیت بر اساس ارزش کل موقعیت اهرمی (وثیقه × اهرم) سنجیده می‌شود، نه فقط وثیقه.
- دادهٔ قدیمی، حد زیان روزانه، افت سرمایه، سقف تعداد معاملات، توقف اضطراری یا وضعیت نامطمئن باعث رد سناریو می‌شود.

## محدودیت مهم
قیمت لیکوییدیشن فعلی تخمین آموزشی است، نه فرمول رسمی صرافی. funding، اسلیپیج، شکاف قیمت، قواعد پلکانی مارجین و همهٔ کارمزدهای واقعی به‌طور کامل مدل نشده‌اند. از این اعداد برای معاملهٔ واقعی استفاده نکنید.

پیش از هر اتصال مالی باید مشخصات رسمی محصول و صرافی مقصد بررسی، آزمون‌های مستقل و تاریخی اجرا، توقف اضطراری و ثبت وقایع ارزیابی و تأیید صریح کاربر دریافت شود. مجوز برداشت یا انتقال وجه نباید لازم باشد.

**وضعیت فعلی: فقط شبیه‌سازی؛ معاملهٔ واقعی خاموش است.**
