# اتصال حد ضرر ATR به شبیه‌ساز اهرمی

این قابلیت فقط برای تمرین و شبیه‌سازی است؛ هیچ اتصال حساب، کلید API یا سفارش واقعی ندارد.

## رفتار
- ATR از کندل‌های OHLC ورودی محاسبه و حد ضرر اولیه بر اساس ضریب ATR ساخته می‌شود.
- ریسک با کل مقدار موقعیت اهرمی محاسبه می‌شود: مقدار دارایی × فاصلهٔ حد ضرر؛ وثیقه به‌تنهایی معیار ریسک نیست.
- اگر ریسک از بودجه بیشتر باشد، موقعیت از ابتدا رد می‌شود؛ اندازهٔ موقعیت بازشده بی‌صدا کوچک نمی‌شود.
- حد ضرر باید از قیمت لیکوییدیشن فاصلهٔ امن داشته باشد؛ مقدار پیش‌فرض این فاصله ۲٪ نسبت به قیمت لیکوییدیشن است.
- هنگام به‌روزرسانی، ابتدا لیکوییدیشن بررسی می‌شود و سپس حد ضرر هوشمند.
- اگر قیمت با شکاف از حد ضرر عبور کند، شبیه‌سازی قیمت بازار مشاهده‌شده را قیمت خروج فرض می‌کند، نه قیمت ایده‌آل حد ضرر.
- پس از بسته‌شدن، فراخوانی دوباره خروج تکراری و کارمزد خروج دوم ایجاد نمی‌کند.

## محدودیت‌های مهم
این مدل قیمت لیکوییدیشن شبیه‌ساز موجود را استفاده می‌کند که تقریبی است و فرمول رسمی هیچ صرافی نیست. Funding، لغزش واقعی، عمق دفتر سفارش، جهش قیمت، کارمزدهای پلکانی، مارجین نگهداری متغیر و قطعی صرافی کامل مدل نشده‌اند. ریسک محاسبه‌شده سقف قطعی زیان نیست و در بازار واقعی ممکن است زیان بیشتر شود. این قابلیت برای معاملهٔ واقعی یا انتخاب اهرم مناسب نیست.
