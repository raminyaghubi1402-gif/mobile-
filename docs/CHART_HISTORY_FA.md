# راهنمای تاریخچهٔ محلی نمودار لی‌لی تریدر

## چه چیزی ذخیره می‌شود؟
صفحهٔ `docs/chart.html` نتیجهٔ تحلیل خودکار (از جمله وضعیت WAIT)، یا سناریوی دستی Entry/SL/TP را در حافظهٔ محلی همان مرورگر ثبت می‌کند. هر رکورد شامل زمان ثبت، نماد، تایم‌فریم، نوع نتیجه، سطوح فرضی و زمان آخرین کندل موجود است.

## حریم خصوصی و محدودیت‌ها
- داده‌ها در `localStorage` مرورگر ذخیره می‌شوند و به API نوبیتکس یا سرور دیگری ارسال نمی‌شوند.
- تاریخچه بین مرورگرها، دستگاه‌ها یا پروفایل‌های کاربری همگام‌سازی نمی‌شود.
- حداکثر ۵۰ مورد اخیر نگهداری می‌شود؛ مورد جدید جایگزین قدیمی‌ترین مورد می‌شود.
- پاک‌کردن داده‌های سایت، حافظهٔ مرورگر یا استفاده از حالت ناشناس ممکن است تاریخچه را حذف کند.
- تاریخچه، دفتر معاملات واقعی نیست و نشان‌دهندهٔ اجرای سفارش یا fill واقعی نیست.
- دکمهٔ «خروجی JSON تاریخچه» یک فایل قابل نگهداری از سوابق فعلی می‌سازد. واردکردن فایل در نسخهٔ فعلی پشتیبانی نمی‌شود.
- اگر مرورگر ذخیره‌سازی محلی را مسدود کرده باشد، صفحه باید پیام عدم امکان ذخیره‌سازی را نشان دهد.

## روش استفاده
1. صفحهٔ نمودار را باز و بازار/تایم‌فریم را انتخاب کنید.
2. «بارگذاری نمودار» را بزنید و منتظر دریافت کندل‌های بسته‌شده بمانید.
3. «تحلیل خودکار لی‌لی» را اجرا کنید؛ نتیجهٔ سناریوی فرضی یا WAIT در تاریخچه ثبت می‌شود.
4. برای ثبت سطوح دستی، Entry و SL و هدف‌ها را وارد و «رسم روی نمودار» را بزنید.
5. در بخش تاریخچه، سوابق را مرور یا با JSON صادر کنید. پاک‌کردن سوابق برگشت‌پذیر نیست.

## آزمون پذیرش دستی
- صفحه را در همان مرورگر دوباره بارگذاری کنید؛ رکوردهای قبلی باید باقی بمانند.
- یک تحلیل با دادهٔ معتبر اجرا کنید؛ یک رکورد PAPER ONLY یا WAIT باید اضافه شود.
- یک سطح دستی معتبر رسم کنید؛ رکورد «سطوح دستی» باید اضافه شود.
- خروجی JSON را بگیرید و ساختار آن را بررسی کنید.
- تاریخچه را پاک کنید و مطمئن شوید فهرست خالی می‌شود.
- حالت ذخیره‌سازی مسدود یا private browsing را جداگانه آزمایش کنید؛ نبود ذخیره‌سازی نباید مانع نمایش نمودار شود.

## مرز ایمنی
این صفحه فقط تحلیل و ثبت سناریوهای آموزشی را انجام می‌دهد. هیچ اتصال حساب صرافی، کیف پول، کلید معامله، سفارش، برداشت یا انتقال وجهی ندارد. وجود Entry/SL/TP در تاریخچه به معنی پیشنهاد قطعی یا معاملهٔ انجام‌شده نیست.
