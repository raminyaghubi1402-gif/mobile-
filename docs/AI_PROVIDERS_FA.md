# راهنمای مدل‌های هوش مصنوعی لی‌لی تریدر

## معماری

- `ai_router.py`: درگاه مشترک برای چند ارائه‌دهندهٔ سازگار با OpenAI Chat Completions.
- `ai_team.py`: سه نقش متوالی «تحلیل‌گر»، «منتقد/کنترل ریسک» و «هماهنگ‌کننده».
- `--ai-review`: بازبینی توضیحی تحلیل قطعی بازار؛ فقط همراه `--market-analysis`.

موتور محاسباتی بازار همچنان مرجع تصمیم قطعی است. مدل زبانی اجازه ندارد تصمیم `READY_BUY`، `READY_SELL` یا `WAIT` را تغییر دهد. مدل فقط گزارش داده‌شده را توضیح و نقد می‌کند؛ قیمت، خبر یا دادهٔ جدید از خودش مجاز نیست.

## پیکربندی چند ارائه‌دهنده

هیچ کلید، حساب یا مدل پولی در مخزن قرار داده نشده است. فهرست ارائه‌دهندگان با متغیر محیطی `LILI_AI_PROVIDERS` و به‌شکل JSON تنظیم می‌شود. هر ارائه‌دهنده باید endpoint سازگار با Chat Completions داشته باشد:

```bash
export LILI_AI_PROVIDERS='[
  {
    "name": "provider-one",
    "base_url": "https://YOUR-ENDPOINT/v1",
    "model": "YOUR-MODEL-ID",
    "api_key_env": "PROVIDER_ONE_KEY",
    "free_tier": true,
    "timeout_seconds": 20,
    "requests_per_minute": 10,
    "cooldown_seconds": 60,
    "max_tokens": 700
  },
  {
    "name": "provider-two",
    "base_url": "https://ANOTHER-ENDPOINT/v1",
    "model": "ANOTHER-MODEL-ID",
    "api_key_env": "PROVIDER_TWO_KEY"
  }
]'
export PROVIDER_ONE_KEY='از محیط امن خود بخوانید'
export PROVIDER_TWO_KEY='از محیط امن خود بخوانید'
PYTHONPATH=src python -m lili_trader --market-analysis --symbol BTCIRT --ai-review
```

مقادیر نمونهٔ endpoint و مدل عمداً placeholder هستند؛ باید با مستندات ارائه‌دهنده‌ای که خودتان انتخاب می‌کنید جایگزین شوند. گزینهٔ `free_tier: true` فقط اعلام کاربر است؛ روتر این ارائه‌دهنده‌ها را جلوتر امتحان می‌کند، اما رایگان‌بودن واقعی، سهمیه یا دسترسی را بررسی یا تضمین نمی‌کند. اگر endpoint به کلید نیاز ندارد، `api_key_env` را حذف کنید. endpointهای غیرمحلی باید HTTPS باشند. endpoint محلی HTTP فقط برای localhost مجاز است.

## رفتار ایمنی و محدودیت

- کلیدها فقط هنگام اجرا از متغیر محیطی خوانده می‌شوند؛ در کد، JSON پیکربندی یا لاگ ذخیره نمی‌شوند.
- پاسخ خطا فقط نام ارائه‌دهنده و کد وضعیت کلی را نگه می‌دارد؛ متن خام خطا/هدر/کلید نمایش داده نمی‌شود.
- timeout، سقف درخواست محلی در دقیقه، cooldown برای ارائه‌دهندهٔ خطادار، cache درون‌حافظه‌ای ۲۴ ساعته با حداکثر ۱۰۰ ورودی و مهار درخواست تکراری کوتاه‌مدت وجود دارد.
- اگر هیچ مدل در دسترس نباشد، fallback محلی اعلام می‌کند که تحلیل هوش مصنوعی در دسترس نیست؛ موتور قطعی مستقل باقی می‌ماند.
- cache و cooldown فعلاً فقط در حافظه‌اند و با restart پاک می‌شوند.
- این پیاده‌سازی خودکار مدل رایگان پیدا نمی‌کند و رایگان‌بودن، سهمیه، دسترسی جغرافیایی یا پایداری هیچ سرویس‌دهنده‌ای را تضمین نمی‌کند. مدل‌های رایگان/آزمایشی را باید از مستندات رسمی همان سرویس بررسی و در فهرست پیکربندی وارد کرد.
- ارائه‌دهنده‌ها باید API سازگار با OpenAI Chat Completions داشته باشند؛ پروتکل‌های اختصاصی بدون adapter جدا پشتیبانی نمی‌شوند.
- خروجی AI توصیهٔ مالی نیست و هیچ سفارش یا معامله‌ای اجرا نمی‌کند.

## اجرای آفلاین و بدون کلید

اگر `LILI_AI_PROVIDERS` تنظیم نشده باشد، دستور `--ai-review` پیام fallback محلی نشان می‌دهد. تحلیل قطعی پرایس‌اکشن و گزارش داده همچنان بدون مدل زبانی قابل استفاده است.
