## امنیت و محدوده
**این نسخه به بروکر، کیف پول یا حساب معاملاتی وصل نمی‌شود و معامله‌ای اجرا نمی‌کند.**
هیچ کلید API مالی در پروژه نیاز نیست. کلیدهای مدل‌ها، در صورت افزودن در آینده، باید فقط در GitHub Actions Secrets یا مخزن امن مناسب ذخیره شوند؛ نه در کد یا لاگ.

امنیت کامل/غیرقابل‌هک بودن قابل تضمین نیست. این پروژه با حداقل دسترسی و بدون دسترسی مالی شروع می‌شود.

## اجرا در GitHub Actions
از تب Actions، گردش‌کار Li-Li Trader CI به‌صورت خودکار روی Push و Pull Request اجرا می‌شود. فعلاً فقط تست‌ها را اجرا می‌کند.

## اجرای محلی (اختیاری)
نیاز: Python 3.11 یا جدیدتر.

    python -m unittest discover -s tests -v
    PYTHONPATH=src python -m lili_trader

## اصل تحلیل
- هیچ قیمت یا خبر ساختگی تولید نمی‌شود.
- تحلیل فعلی روی دادهٔ نمونه است و تحلیل زندهٔ بازار نیست.
- قبل از نمایش تحلیل زنده، منبع و زمان داده باید ثبت و اعتبارسنجی شود.
- خروجی ابزار آموزشی است و توصیهٔ قطعی مالی نیست.
