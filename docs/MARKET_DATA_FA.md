# دریافت دادهٔ بازار

## رمزارز
نسخهٔ اولیه از endpoint عمومی و فقط‌خواندنی کندل‌های Binance Spot استفاده می‌کند:
- endpoint: `/api/v3/klines`
- بدون API key برای این endpoint عمومی
- فقط خواندن داده؛ هیچ endpoint سفارش/معامله در کد وجود ندارد.

دسترسی از شبکه، محدودیت جغرافیایی، شرایط سرویس و نرخ درخواست ممکن است تغییر کند. خطا یا قطع اتصال باید به‌صورت «داده در دسترس نیست» گزارش شود؛ نباید قیمت قبلی به‌عنوان قیمت جدید نمایش داده شود.

## فارکس
در این مرحله قیمت زندهٔ فارکس فعال نیست. برای افزودن آن باید یک ارائه‌دهندهٔ مشخص انتخاب شود و سهمیه، شرایط استفاده، نیاز به کلید، منطقهٔ قابل دسترس و زمان‌بندی داده بررسی شود. تا آن زمان EUR/USD و سایر جفت‌ها نباید به‌عنوان قیمت زنده نمایش داده شوند.

## تازگی داده
هر کندل شامل زمان آغاز کندل و زمان دریافت از سیستم است. این زمان‌ها یکسان نیستند؛ کندل ممکن است هنوز در حال شکل‌گیری باشد. گزارش فعلی زمان‌ها را به UTC نمایش می‌دهد.

## حریم خصوصی و کلیدها
- endpoint عمومی رمزارز در این نمونه به کلید احتیاج ندارد.
- کلیدهای احتمالی providerهای آینده فقط در GitHub Actions Secrets یا secret manager ذخیره شوند.
- از ثبت کلید در log، فایل عمومی، issue یا commit خودداری شود.
