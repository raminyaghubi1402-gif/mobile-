# پایش زنده و معاملات آزمایشی لی‌لی

## محدوده

این ابزار فقط دادهٔ عمومی کندلی Nobitex را برای BTCIRT و ETHIRT می‌خواند. هیچ حساب صرافی، توکن، کیف پول، سفارش واقعی یا معامله با پول واقعی ندارد.

Workflow هر ۱۵ دقیقه اجرا می‌شود تا فرصت استفاده از کندل‌های ۵ دقیقه‌ای بسته‌شده را داشته باشد. در هر نوبت، تایم‌فریم‌های ۱ساعت، ۱۵دقیقه و ۵دقیقه بررسی می‌شوند.

## کنترل داده

- فقط کندل‌هایی وارد تحلیل می‌شوند که زمان بسته‌شدنشان گذشته باشد.
- از آخرین قطعهٔ پیوستهٔ داده استفاده می‌شود؛ شکاف زمانی هرگز با حدس، میان‌یابی یا انتقال قیمت پر نمی‌شود.
- اگر دادهٔ تازه، پیوسته یا کافی نباشد، آن نماد در همان نوبت بدون معامله می‌ماند.
- روند ۱ساعته و ۱۵دقیقه، ساختار بسته‌شدن‌محور BOS/CHoCH در ۵دقیقه و ناحیهٔ حمایت تأییدشده بررسی می‌شوند.
- طبق سیاست فعلی، بازار رنج و روند نزولی در حالت Spot به معنی WAIT است.

## موتور فعال

فعلاً فقط موتور مستقل `trend_pullback` به مسیر زنده متصل است. شش موتور دیگر تا زمان پیاده‌سازی و آزمون انتهابه‌انتها غیرفعال می‌مانند.

سیگنال BUY فقط یک تصمیم آزمایشی است. اگر سیگنال معتبر ثبت شود:
1. ورود در قیمت بسته‌شدن همان کندل انجام نمی‌شود.
2. سیستم منتظر کندل ۵دقیقهٔ بعدی می‌ماند و قیمت بازشدن آن را مبنای ورود شبیه‌سازی‌شده می‌گیرد.
3. اگر کندل بعدی به‌علت شکاف زمانی وجود نداشته باشد، یا قیمت بازشدن باعث شود نسبت سود به زیان واقعی کمتر از ۱:۱٫۵ شود، ورود لغو می‌شود.
4. حجم موقعیت با بودجهٔ ریسک آزمایشی و سقف نقدینگی بدون اهرم محدود می‌شود.

در مدیریت موقعیت، کارمزد و لغزش مدل می‌شوند. اگر حدضرر و هدف در یک کندل لمس شوند و ترتیب درون‌ کندل معلوم نباشد، فرض محافظه‌کارانه این است که حدضرر زودتر فعال شده است.

## نگهداری وضعیت

دفتر تصمیم‌ها در فایل JSONL زنجیره‌هش‌شده ثبت می‌شود. وضعیت سفارش‌های در انتظار و موقعیت‌های باز آزمایشی در فایل JSON جداگانه نگهداری می‌شود. Workflow زمان‌بندی‌شده از GitHub Actions cache برای انتقال این دو فایل بین اجراها استفاده می‌کند.

اجرای pull request عمداً cache دائمی را تغییر نمی‌دهد. زمان‌بندی خودکار روی شاخهٔ پیش‌فرض GitHub فقط پس از بررسی و ادغام PR فعال می‌شود. اگر cache بازیابی نشود یا فایل وضعیت خراب باشد، سیستم وضعیت را خودکار پاک نمی‌کند و اجرا را متوقف می‌کند تا تاریخچهٔ معاملهٔ آزمایشی از بین نرود.

## گزارش و محدودیت

نتایج paper trading با بک‌تست تاریخی جدا هستند. گزارش هر اجرا تعداد تصمیم‌های BUY/WAIT، موقعیت‌های باز، معاملات بسته‌شده و PnL خالص پس از هزینه‌ها را نشان می‌دهد. نبود سیگنال به‌معنی «بدون معامله» است، نه خطا.

یک اجرای آزمایشی روی PR در ۲۵ نوامبر ۲۰۲۶ برای هر دو نماد دادهٔ تازه دریافت کرد؛ ساختار ۱۵دقیقه‌ای هر دو نماد رنج بود و هر دو تصمیم WAIT ثبت کردند. این اجرا دو تصمیم و صفر معامله داشت و هیچ نتیجه‌ای دربارهٔ سودآوری نمی‌دهد.

این ابزار هنوز یک موتور دارد و برای ارزیابی سودآوری، نمونهٔ معاملات و دورهٔ آزمون خارج از نمونهٔ بسیار بیشتری لازم است. آماده‌بودن برای معاملهٔ واقعی از این نتایج استنباط نمی‌شود.
