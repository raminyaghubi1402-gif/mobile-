# نمودار: محافظ دادهٔ تازه

در تحلیل خودکار، کندل‌های بسته‌شدهٔ ۱h، ۱۵m و ۵m باید تازه باشند. معیار محافظ:

- زمان بسته‌شدن آخرین کندل محاسبه می‌شود؛ فقط یک فاصلهٔ کندلی پس از بسته‌شدن مجاز است.
- timestamp نامرتب/نامعتبر، کندل هنوز بسته‌نشده، یا شکاف غیرعادی بین دو کندل آخر، داده را رد می‌کند.
- اگر یکی از سه تایم‌فریم اصلی قدیمی یا ناقص باشد، `mtfReady` false می‌ماند و تحلیل ورود متوقف می‌شود.
- دادهٔ روزانه/۴h که قدیمی است به‌عنوان زمینه حذف می‌شود و هشدار می‌دهد؛ زمینهٔ اختیاری نباید تحلیل اصلی را فعال کند.
- نمودار دستی ممکن است داده را نشان دهد، اما محافظ تازگی تحلیل خودکار را fail-closed می‌کند.
- این محافظ، freshness را تضمین دائمی نمی‌کند؛ زمان‌بندی شبکه و API همچنان ممکن است تغییر کند.

CI تست JavaScript مستقل برای تازگی و محدودیت دو نماد را اجرا می‌کند.
